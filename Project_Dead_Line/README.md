# Project Deadline Checker

## Description

A beginner Python program that checks the remaining time before a project deadline.

The program asks the user to enter a project title and deadline, then calculates the number of days remaining from the current date.

## Features

- Accepts a project title
- Accepts a project deadline
- Validates the date format
- Calculates the remaining days
- Identifies overdue projects
- Provides warnings for approaching deadlines
- Gives an urgent reminder when 3 days remain

## Technologies Used

- Python
- datetime module
- Jupyter Notebook
